# CS2 Configs

A collection of my personal Counter-Strike 2 configuration files.

I created this repository to keep my configs backed up, organized, and easy to install on a new system.

## Installation

1. Download or clone this repository.

2. Copy the `.cfg` files into your CS2 config directory:

   `~\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg`

3. Start Counter-Strike 2 and open the developer console.

4. Execute the config:

   `exec <config_name>`
